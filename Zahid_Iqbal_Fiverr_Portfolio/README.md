# Zahid.dev — Fiverr Portfolio

A responsive, premium dark portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page structure and portfolio content
- `style.css` — layout, responsive design and visual styling
- `script.js` — navigation, animations, typing effect and external links

## Before publishing

Open `script.js` and replace:

```js
const PORTFOLIO_LINKS = {
  fiverr: "https://www.fiverr.com/yourusername",
  github: "https://github.com/yourusername"
};
```

with your real Fiverr and GitHub URLs.

## Run locally

Open `index.html` directly in a browser, or use VS Code + Live Server.

## Recommended Fiverr use

Use screenshots from the project cards as Fiverr portfolio images, and keep each Fiverr gig targeted to one service:
- Data Cleaning + EDA + Visualization
- Machine Learning + Flask API + Docker + CI/CD + MLOps
